# RE:ICA Manga Lab — Pages

Четвёртая вкладка встроенной панели **Window → MangaLab → Pages**.

## Начало работы

1. Открой один PSD со страницами манги.
2. Убедись, что **каждая страница — отдельный слой или группа верхнего уровня**. Если несколько страниц объединены на одном растровом слое, сначала раздели их на отдельные слои. Эта версия не вырезает отдельные страницы из одного изображения.
3. Выдели эти слои/группы в панели Layers. Для всех доступных страниц можно выключить опцию **Selected top-level layers only**. Фоновый Background, существующие группы с именем Page и монтажные области (Artboards) не обрабатываются.
4. Выбери первый номер страницы, при необходимости включи **Reverse page numbering** (нумерация в обратную сторону относительно порядка слоёв).
5. Включи или отключи **Auto-fill speech bubbles**. При необходимости укажи форму, минимальный размер, порог белого, цвет заливки и сохранение границы обводки.
6. Нажми **Create Page Groups + Clean**.

## Результат

Для каждого выбранного слоя/группы появляется структура:

```text
Page 001
  clean
    bubble_fills       # прозрачный растровый слой для замазки
  source
    <исходная страница> # оригинальные слои/группы сохранены
Page 002
  clean
    bubble_fills
  source
    <исходная страница>
```

Автозамазка находится отдельно от исходной страницы; её можно править обычными инструментами PhotoCraft. Всё действие создаёт одну запись Undo. Повторное применение следует делать только к ещё не сгруппированным исходным слоям.

## Настройки

- **Selected top-level layers only**: использовать выделенные страницы, по умолчанию включено.
- **Reverse page numbering**: обратная нумерация страниц без изменения их порядка в панели Layers.
- **First page number**: начальный номер.
- **Auto-fill speech bubbles**: попытка замазать баблы на `bubble_fills`.
- **Detect round/oval** и **Detect rectangular**: типы замкнутых светлых областей.
- **Sample interior color**: цвет определяется по средней светлой заливке; при выключении используется чистый белый.
- **Minimum size**: минимальная ширина и высота обнаруживаемой области.
- **White threshold**: насколько светлой должна быть внутренняя область бабла (150–250).
- **Protect outline**: пиксели внутреннего отступа, чтобы сохранить чернильную обводку.

## Ограничения и безопасность

- Детектор является **эвристическим**, а не семантическим распознавателем речи. Он ищет достаточно светлые, замкнутые области в самом крупном растровом слое страницы. Другие слои не смешиваются при определении пузыря.
- Области, примыкающие к границе страницы, стилизованные/разомкнутые баблы, тёмные надписи на тёмном фоне, текстурированные или градиентные фоны могут быть пропущены.
- Возможны ложноположительные срабатывания на светлых элементах иллюстрации. Проверяй результат по каждой странице, особенно перед сохранением. Можно отключить созданный `clean` или Undo.
- Для обработки одной страницы ограничено количество анализируемых пикселей (12 млн), чтобы не выделять неограниченный объём памяти. Страницы большего размера получают пустой слой замазки.
- Сохранение PSD протестировать отдельно в Windows UI. На больших документах сначала делай резервную копию PSD.

- `crates/ui-egui/src/text_library.rs`: вкладка, сохранение параметров и UI.

- `crates/engine/src/cmd.rs`: регистрация команды.
- `crates/ui-egui/src/canvas/tool_input.rs`: совместимость свободного редактирования символов с новой архитектурой ввода PhotoCraft.
