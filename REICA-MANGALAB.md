## 1. Что такое MangaLab

**RE:ICA Manga Lab** (коротко **MangaLab**) — набор встроенных в форк PhotoCraft инструментов для набора и оформления текста, особенно манги, звуков и декоративных надписей.

Это **не отдельный внешний плагин** с собственным установщиком: панель, текстовые команды, отрисовка и обработка событий интегрированы в Rust-код редактора. Внешний вид и размещение панели обеспечиваются обычной docking-системой PhotoCraft.

Основные части:

1. **Fonts** — избранные шрифты, пользовательские группы и быстрый выбор.
2. **Styles** — сохранённые наборы эффектов текстового слоя.
3. **Effects** — автоматические редактируемые эффекты **Random / Decrease / Alternating**.
4. **Freeform Text** — ручное перемещение, вращение и масштабирование отдельных символов и выделенных групп непосредственно на холсте.

**Главный принцип:** текст остаётся текстом. Для эффектов и ручной трансформации не требуется превращать его в растр, смарт-объект или создавать отдельный слой на каждую букву.

### Названия и совместимость

| Что | Значение |
| --- | --- |
| Полное название | **RE:ICA Manga Lab** |
| Короткое название в меню `Window` | **MangaLab** |
| Название приложения | **PhotoCraft [RE:ICA Edition]** |
| Cargo package приложения | `photocraft-reica` |
| Собираемый Windows-файл | `photocraft-reica.exe` |
| Существующий внутренний ID панели | `textLibrary` |
| Команда для панели | `window.panel.textLibrary` |
| Внутренняя группа пресетов эффектов | `Text Library` |

**Почему остались старые внутренние идентификаторы?** Чтобы существующие избранные шрифты, сохранённые стили, записи настроек и расположение панели не пропали только из-за переименования. Имя GitHub-репозитория и большинство внутренних Rust-крейтов `photocraft-*` также пока не менялись.

## 2. Как открыть и использовать панель

1. Запустить **PhotoCraft [RE:ICA Edition]**.
2. Открыть `Window → MangaLab`.
3. Переключить нужную вкладку `Fonts`, `Styles` или `Effects`.
4. Выделить существующий **Type layer** (текстовый слой) либо войти в режим редактирования текста, если функция должна применяться к тексту.

### Конструкция интерфейса

- Панель является обычной докируемой панелью: её можно размещать вместе с другими вкладками, откреплять и менять размер.
- Вкладки **Fonts** и **Styles** используют **сетку из трёх колонок**, независимо от числа карточек. Четвёртый элемент переходит на следующую строку.
- Интервал между карточками: **5 px**; высота карточки: **79 px** (константы исходников).
- Карточки автоматически подстраиваются под фактическую ширину панели; длинные названия обрезаются по видимой области.
- Список карточек прокручивается по вертикали.
- Заголовок, выбор группы и область удаления не уезжают вместе с карточками.
- Внизу расположен блок **Drag here to remove**: перетащить карточку в эту область для удаления из коллекции. Обычное нажатие на карточку удалением не считается.
- Контекстное меню карточки также предлагает удаление.
- У карточек есть превью: для шрифта рисуется пример установленным шрифтом, для стиля — настоящая отрисовка текста `Aa` с применёнными эффектами слоя.
- Превью стилей кэшируются (до **64** текстур), чтобы не пересчитывать всё при каждом кадре.

Код: [`crates/ui-egui/src/text_library.rs`](crates/ui-egui/src/text_library.rs), [`crates/ui-egui/src/panel_docking.rs`](crates/ui-egui/src/panel_docking.rs).

## 3. Fonts — библиотека шрифтов

**Назначение:** хранить часто используемые установленные шрифты для быстрого переключения при оформлении страниц манги.

### Возможности

- Добавление установленного шрифта через кнопку `+` и стандартный поиск/выбор семейства.
- Применение шрифта к выбранному текстовому слою или текстовому выделению нажатием на карточку.
- Создание **именованных групп** через `+ Group`.
- Переключение активной группы в выпадающем меню.
- Отдельная стандартная группа `Default`.
- Проверка наличия шрифта в системе перед добавлением.
- Запрет дублирования шрифта **внутри одной группы**.
- Удаление шрифта из группы через корзину или контекстное меню.
- Название новой группы: до **64 символов**, без дубликатов с игнорированием регистра.

### Звёздочка у выбора шрифта

Звёздочка `☆ / ★` встроена в элементы выбора шрифтов редактора.

- **Обычный клик** — показать список групп и выбрать, куда добавить шрифт.
- **Shift + клик** — сразу добавить шрифт в текущую активную группу.
- `★` показывает, что шрифт уже есть в активной группе.

Для применения используется обычная команда `type.setStyle`, поэтому не создаётся новый слой.

### Где хранятся данные

В общих пользовательских настройках PhotoCraft (`crates/engine/src/prefs.rs`):

- `text_library_fonts` — избранные в группе `Default`.
- `text_library_groups` — список пользовательских групп и шрифтов внутри каждой.
- `text_library_active_group` — активная группа.

Избранные шрифты **не встраиваются в сам `.pcraft`**. Для переноса на другой компьютер используется отдельный `.pcraftfp` — он содержит **настоящие файлы шрифтов**, а не только их имена (см. раздел 14).

## 4. Styles — библиотека стилей слоя

**Назначение:** один раз собрать оформление текстового слоя, а затем быстро применять его к другим надписям.

### Что сохраняется

Только **эффекты слоя** (например, те эффекты, которые уже поддерживает движок PhotoCraft).

**Не сохраняются** текст надписи, шрифтовое семейство, размер шрифта, цвет символов, межбуквенные интервалы и настройки абзаца. Это осознанное разделение: один эффект можно применить к надписям с разными шрифтами.

### Работа

1. Выделить текстовый слой с настроенными эффектами.
2. Открыть вкладку `Styles` и нажать `+`.
3. Команда `style.presets.new` сохраняет пресет в группе `Text Library`.
4. Нажатие на карточку применяет его к выбранному текстовому слою.
5. Команда `layer.layerStyle.replace` **заменяет набор эффектов**, не переписывая основную текстовую типографику.
6. Карточку можно удалить из списка; пресет хранится в обычной системе пресетов редактора и переживает перезапуск.

Для создания пресета слой должен уже иметь хотя бы один эффект. Превью карточки собирается с участием реального текстового движка и композитора, а не CSS-имитацией.

**Важно:** при применении стиля текущие эффекты слоя **заменяются**, а не объединяются с новыми.

Код: `library_styles()`, `save_style()`, `apply_style()`, `render_style_preview()` в [`text_library.rs`](crates/ui-egui/src/text_library.rs).

## 5. Effects — автоматические эффекты редактируемого текста

**Назначение:** быстро распределять оформление по отдельным буквам без ручного разделения текста на слои.

Вкладка `Effects` открывает параметры и кнопку `Apply to text`. Можно выделить конкретные символы инструментом Type; если диапазон не выделен, эффект применяется ко всему выбранному текстовому слою.

Внутренняя команда: **`type.textEffect`**.

### 5.1. Random

Для каждого символа задаются случайные (но воспроизводимые) значения:

- Масштаб *размера шрифта* как доля текущего размера: `minPercent` / `maxPercent` (**10–400%**).
- Угол наклона: `minRotation` / `maxRotation` (от **−30° до +30°**).
- `seed` — числовое зерно случайности; кнопка `New seed` выдаёт следующую вариацию.

Алгоритм использует детерминированную последовательность **SplitMix64**. При одинаковом тексте, параметрах и seed результат повторяем. Изменения разных букв задаются отдельными индексами, а случайный размер и поворот получают разные независимые значения.

### 5.2. Decrease (Taper)

Постепенное изменение размера букв по всей последовательности:

- **Normal:** от размера первой обрабатываемой буквы до указанного `endSize`.
- **Reverse:** в обратном направлении, от граничного размера к исходному.
- Параметр `endSize` задаётся в **pt**.

Текущая реализация предназначена для уменьшения: конечный размер ограничен исходным размером первой буквы.

### 5.3. Alternating

Чередование двух наборов значений через одну букву:

- большая / маленькая;
- поворот в одну / другую сторону;
- используются те же минимум и максимум процента размера и угла, что в Random.

### Технические особенности эффектов

- Эффекты модифицируют **`CharStyle` внутри `TextRun`**, а не пиксели.
- Для Random и Alternating меняются `size_pt` и `rotation_deg`.
- Для Decrease меняется `size_pt`.
- Переводы строк пропускаются.
- Символы обрабатываются по Unicode, с учётом переменной длины UTF-8.
- Каждое нажатие `Apply to text` — отдельное действие Undo/Redo.
- Повторное применение использует **текущие** размеры букв как исходные; в особенности Random/Alternating могут накапливать эффект.
- Текст остаётся редактируемым в обычном Type tool.

Пример команды для движка:

```json
{
  "layer": 123,
  "mode": "random",
  "minPercent": 75,
  "maxPercent": 125,
  "minRotation": -12,
  "maxRotation": 12,
  "seed": 1
}
```

Технический модуль: [`crates/engine/src/text_effects.rs`](crates/engine/src/text_effects.rs).  
Интерфейс параметров: `effect_panel()` и `run_text_effect()` в `text_library.rs`.

## 6. Freeform Text — ручная трансформация букв

**Назначение:** свободно разложить надпись по холсту — например, изогнуть звук или сделать неравномерный заголовок манги, **не теряя возможности переписать текст**.

Freeform Text — **режим существующего инструмента Type**, а не дополнительный тип слоя. Включается переключателем **`◎ Freeform Text`** на верхней панели параметров Type tool.

### Управление

| Действие | Результат |
| --- | --- |
| Перетащить **центральную точку** буквы | Свободно изменить положение по X/Y |
| Перетащить **кольцо** вокруг точки | Повернуть отдельную букву |
| Перетащить **квадратик** над буквой справа | Масштабировать букву |
| **Shift + клик** по маркерам разных букв | Добавить/убрать буквы из группового выделения |
| Тянуть маркер одной из выделенных букв | Переместить, повернуть или масштабировать выделенные буквы **вместе** |
| **Shift при вращении** | Привязка угла к шагу **15°** |
| **Alt + клик** по маркеру | Сбросить ручное смещение, угол и масштаб выбранной буквы |
| Выключить `Freeform Text` | Скрыть ручки трансформации и продолжить обычную работу с текстом |

Выделенные буквы показываются другим цветом, а для группы из нескольких символов рисуется общий центр. Поворот и масштаб группы рассчитываются относительно этого центра; перемещение сдвигает каждую выбранную букву одинаково.

Каждая операция перетаскивания передаёт в `type.edit` один пакет изменений и один ключ `coalesce`, чтобы её можно было отменить одной командой Undo.

### Параметры каждого символа

В `CharStyle` добавлены отдельные поля:

| Поле модели | Командный JSON-ключ | Назначение | Значение по умолчанию |
| --- | --- | --- | --- |
| `freeform_x` | `freeformX` | Смещение по X в координатах текста | `0.0` |
| `freeform_y` | `freeformY` | Смещение по Y | `0.0` |
| `freeform_angle` | `freeformAngle` | Свободный поворот, градусы | `0.0` |
| `freeform_scale` | `freeformScale` | Множитель ручного масштаба | `1.0` |
| `rotation_deg` | Используется движком текстовых эффектов | Автоматический поворот (Random/Alternating) | `0.0` |

Ручное масштабирование отделено от `size_pt`. Поэтому оно меняет визуальную величину символа **без обязательного перерасчёта типографического размера шрифта**. Это отличие от автоматических эффектов, которые изменяют именно `size_pt`.

Результирующий поворот объединяет `rotation_deg` и `freeform_angle`. Тем самым автоматические эффекты можно сочетать с последующей ручной правкой.

### Как символы связаны с редактируемой строкой

- В UI трансформации адресуются индексами символов (`start` / `end`).
- Движок переводит их в диапазоны **UTF-8 байтов**, которыми размечены `TextRun`.
- На холсте управляющие точки строятся по кластерам текстовой раскладки (`TextLayout.clusters`), что позволяет выделять составные графемы вместе.
- Если вставить символ перед уже оформленной буквой, свойства существующей буквы следуют за её позицией.
- Если заменить один символ другим, первый заменённый символ наследует прежнюю свободную трансформацию.
- У вновь добавленных символов ручные смещения/вращение/масштаб сбрасываются до значений по умолчанию. При этом обычные свойства шрифта наследуются.
- Удаление части строки удаляет соответствующие диапазоны стилей.

Пример: у буквы `Б` в `АБВ` задан поворот +30°. Если вставить `Я` в начале, получится `ЯАБВ`, и поворот останется у `Б`. Замена самой `Б` на `О` сохраняет оформление этой позиции.

### Как работает рендер

1. Обычный движок выполняет формирование строк и глифов.
2. Для глифов определяются стили.
3. К графике символов добавляются отдельные масштаб, поворот и смещение.
4. В кэше текстового слоя обновляется изображение, но **источник остаётся текстом**.
5. Перерисовка документа учитывает область изменений слоя.

Визуальный центр маркеров берётся из геометрии текстовых кластеров — это **практический ориентир**, а не всегда точный математический центр контура любого шрифта.

Код взаимодействия: [`crates/ui-egui/src/freeform_text.rs`](crates/ui-egui/src/freeform_text.rs).  
Рендер: [`crates/text/src/render.rs`](crates/text/src/render.rs).  
Типографическая модель: [`crates/doc/src/text.rs`](crates/doc/src/text.rs).

## 7. Хранение данных и отличие временного состояния от документа

| Данные | Где сохраняются |
| --- | --- |
| Избранные шрифты, списки групп, активная группа | Пользовательские настройки `Preferences` |
| Сохранённые наборы эффектов во вкладке Styles | Система пресетов приложения, группа `Text Library` |
| Активная вкладка и параметры формы Effects | Состояние интерфейса панели (`text_library::State`) |
| Сам текст, размеры и стили его символов | Данные текстового слоя документа |
| Freeform-смещения, вращение, масштаб | `CharStyle` / `TextRun` в текстовом слое; в родном `.pcraft` |
| Текущее выделение нескольких букв и незавершённый drag | **Только временное состояние UI**, не в файле документа |
| Положение док-панели и конфигурация интерфейса | Состояние рабочего пространства редактора |

**Не путать:** `Styles` и `Effects` — разные вещи. Первая вкладка сохраняет **эффекты слоя** как пресеты, вторая применяет **параметры к символам** прямо в тексте.

Нативный `.pcraft` — основной формат для сохранения авторских Freeform Text-трансформаций. Сохранение в PSD **не гарантирует** сохранения этих новых свойств как редактируемого текста; задача полной PSD-совместимости в этот набор изменений не входила.

## 10. Тесты и проверки качества

В исходниках добавлены тесты на следующие сценарии:

- Сохранение Freeform-значений при вставке символов перед изменённой буквой, включая **кириллицу / UTF-8**.
- Наследование параметров при замене символа на той же позиции.
- Сброс Freeform-параметров у новых символов.
- Сериализация `CharStyle` и значения по умолчанию для старых данных.
- Групповое перемещение двух раздельно выделенных букв.
- Групповое масштабирование относительно общего центра.
- Ранее существовавшие тесты для режимов автоматических текстовых эффектов.

### Что стоит проверить вручную в первую очередь

1. Обычный текстовый слой: вкл./выкл. Freeform и редактирование надписи после трансформаций.
2. Реакцию кружков и колец при разных уровнях zoom и повороте/отражении вида.
3. Сохранение `.pcraft`, закрытие, повторное открытие и совпадение положения букв.
4. Undo/Redo после одного перемещения и после группового преобразования.
5. Замены букв, вставку текста в середину строки, удаление, кириллицу, составные Unicode-символы.
6. Длинные надписи, крупные смещения, сильный поворот и масштаб — нет ли обрезания глифов.
7. Сочетание `Random` / `Decrease` / `Alternating` с Freeform Text.
8. Вертикальный текст, текст внутри рамки и, отдельно, текст по кривой.
9. Загрузка ранее созданных избранных шрифтов, групп и Styles после ребрендинга.
10. Сборку и запуск файла именно под именем `photocraft-reica.exe`.

## 11. Текущие ограничения и инженерные замечания

- **Совместимость с PSD не является целью** этой реализации. Для проектов с ручными трансформациями предпочтителен `.pcraft`.
- **Отдельный установщик MangaLab не создан:** это часть форка приложения.
- **Независимое ручное выделение букв хранится только в UI:** после перезапуска документа выделение надо сделать снова, сами трансформации остаются в документе.
- **Группы шрифтов не являются каталогами файлов шрифтов:** здесь хранятся имена установленных семейств.
- **Styles заменяет эффекты слоя**, а не смешивает два набора эффектов.
- **Random/Alternating изменяют размер шрифта**, Freeform Scale — визуальный множитель глифа.
- **Не весь редактор переименован:** внутренние package/crate IDs, часть идентификаторов PhotoCraft, фирменные иконки и системные интеграции оставлены в первоначальном виде во избежание каскада несовместимостей.
- **Повороты, деформации, сложное шейпирование и нестандартные глифы** требуют дополнительного ручного тестирования на точность hit-test и расположение управляющих маркеров.
- **Особо длинные перемещения символов** требуют проверки корректного расширения границ растрового кэша и области повреждения холста.
- В ветке пока **нет подтверждённой успешной Windows-сборки**. Не следует считать перечисленное гарантированно протестированным релизом.

- **Менять карточки и вкладки** → `crates/ui-egui/src/text_library.rs`.

- **Добавить новое свойство отдельной буквы** → `CharStyle` в `crates/doc/src/text.rs`, обработчик JSON в `type_cmds.rs`, применение при отрисовке в `render.rs` и тесты.

## 14. Font Packs (.pcraftfp) — экспорт и импорт шрифтов с файлами

**RE:ICA Manga Lab** поддерживает перенос пользовательских групп **вместе с исходными TTF/OTF/TTC-файлами**, без ручной установки каждого шрифта в операционную систему.

### Экспорт

1. Перейти в `Window → MangaLab → Fonts`.
2. Выбрать нужную группу, в том числе `Default`.
3. Нажать `Export…` и указать имя `НазваниеГруппы.pcraftfp`.
4. Получить ZIP-архив с собственным расширением `.pcraftfp`: файл `manifest.json` содержит название группы и семейства, а каталог `fonts/` — реальные бинарные шрифты, включая доступные начертания (regular/bold/italic/variable).

Группа с отсутствующими на данном компьютере шрифтами **не экспортируется неполностью**: будет показано сообщение о недоступном семействе. Такой шрифт необходимо установить или убрать из группы.

### Импорт

1. На другом компьютере открыть `Window → MangaLab → Fonts → Import…`.
2. Выбрать `.pcraftfp`. Импорт проверяет формат/версию, имена, размеры и заголовки файлов, а не распаковывает произвольные пути из ZIP.
3. Движок проверяет настоящие шрифтовые файлы, сохраняет их в собственной папке `MangaLabFonts` внутри каталога настроек приложения и регистрирует шрифты в текущей сессии.
4. Если группа с таким именем существует, её список **дополняется без удаления старых позиций**. Повторяющиеся названия пропускаются. Для отсутствующей группы создаётся новая. `Default` используется как встроенная группа, а не как ещё одна пользовательская.
5. При следующем запуске редактор считывает ранее импортированные бинарные шрифты из `MangaLabFonts` автоматически.

Импорт **не устанавливает шрифты глобально в Windows/macOS/Linux** — они становятся доступны самому PhotoCraft [RE:ICA Edition]. Это сделано специально, чтобы не изменять системные настройки без необходимости.

### Технический формат

Файл `.pcraftfp` — ZIP с `manifest.json` (формат `reica.mangalab.font-pack`, версия **2**), путями внутри `fonts/` и бинарными данными TTF/OTF/TTC. Имена группы и шрифтов записываются как Unicode-строки; формат переносим между платформами.

Защитные ограничения: архив до **160 МиБ**, распакованные данные до **128 МиБ**, отдельный шрифт до **32 МиБ**, до **512 семейств** и **1024 исходных файлов**. Пути из архива никогда не используются напрямую в пользовательской файловой системе.

Код: [`crates/ui-egui/src/font_pack.rs`](crates/ui-egui/src/font_pack.rs), UI-кнопки — `text_library.rs`, доступ к бинарным начертаниям — `FontDb::family_font_data()` в `crates/text/src/fonts.rs`. Включена проверка восстановления данных и объединения групп.

### Лицензии шрифтов

**Наличие шрифта на компьютере не означает разрешение на его распространение.** Перед отправкой `.pcraftfp` другим людям проверьте условия лицензии каждого шрифта. Редактор не может достоверно определить все лицензионные ограничения автоматически, поэтому экспорт не гарантирует права на распространение.

### Текущий статус

Код и тесты добавлены в рабочую ветку. Успешная сборка и практическая проверка пакетов после перезапуска редактора ещё не подтверждены, особенно на мобильных и веб-сборках.
